DLSSG Mod Manager 0.3.0 makes game management easier to follow while keeping the original navy and mint colors.

- **Game management:** choose a Steam game, folder or rendering EXE, then read a clear compatibility result and the next step. Relevant installation blockers are shown beside the result.
- **Mod settings:** all ten existing controls have their own page, with 2× retained as the recommended starting point.
- **Diagnostics:** full checks, package and hardware details, game logs, disable and restore tools remain available together.
- A persistent action area keeps installation and game launching easy to find. The online-game ban warning remains prominent.
- The manager-update notice appears only when a newer stable release is available. The production build supports normal installation, launching and in-app updates; the local read-only preview is a separate build.
- Navigation, interface text and documentation are updated in all 11 languages.

**Updating:** users on 0.2.2 or 0.2.3 can choose **Update and restart** when 0.3.0 is offered. MSI installations still on 0.2.0 or 0.2.1 need one manual installation of the latest MSI: close the manager and run this release's MSI in the same installation folder. Their older updater may fail with Windows Installer error 1639. Portable installations are unaffected by this MSI issue. Users on 0.1.0 must update manually once because that version has no updater.

Manager updates are separate from game mod updates. The reviewed upstream recipe remains **0.4.1**. Use the mod only in offline single-player games; no ban protection or bypass is provided.

The manager and MSI remain unsigned. Original mod: **sdli1995** and contributors; RTX 20 / SM75 adaptation: **Coldwood1026**. See the README and third-party notices.
