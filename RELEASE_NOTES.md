DLSSG Mod Manager 0.1.0 is the first public preview.

It provides verified official release downloads, manual and Steam game selection, GPU/game prerequisite checks, all player-facing mod options with 2× defaults, transactional installation and restoration, and runtime log verification in 11 languages.

The initial reviewed upstream recipe is DLSSG for SM86 0.4.1. Unknown future recipes are downloaded but blocked for installation until the manager supports their requirements. Unknown old manual installations are treated as conflicts. This preview is unsigned; review the README and third-party notices before distribution.
