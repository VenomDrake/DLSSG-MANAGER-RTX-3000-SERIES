DLSSG Mod Manager 0.3.1 makes the already-current mod status easier to recognize.

- The bottom action area shows **You already have the latest version** in mint green when the selected game already has the current mod version.
- Other states retain their usual color, including when a game selection changes or installation checks block an action.
- The status works in all 11 manager languages. Installation, compatibility checks and update behavior are unchanged.

**Updating:** choose **Update and restart** when this release is offered. MSI installations still on 0.2.0 or 0.2.1 need one manual installation of the latest MSI because their older updater may fail with Windows Installer error 1639. Users on 0.1.0 also need one manual update.

Use the mod only in offline single-player games; no ban protection or bypass is provided. The reviewed upstream recipe remains **0.4.1**. Original mod: **sdli1995** and contributors; RTX 20 / SM75 adaptation: **Coldwood1026**. See the README and third-party notices.
