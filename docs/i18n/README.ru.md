# DLSSG Mod Manager

**Читать на:** [English](../../README.md) · [Italiano](README.it.md) · [简体中文](README.zh-Hans.md) · [हिन्दी](README.hi.md) · [Español](README.es.md) · [Français](README.fr.md) · [العربية](README.ar.md) · [বাংলা](README.bn.md) · [Português](README.pt.md) · **Русский** · [اردو](README.ur.md)

Настольное приложение для Windows, дополняющее [DLSSG for SM86](https://github.com/sdli1995/dlssg_for_sm86): проверяет ПК и игру, устанавливает проверенный пакет мода и сохраняет историю изменений с возможностью восстановления.

## Благодарности

- **Оригинальный мод:** [DLSSG for SM86](https://github.com/sdli1995/dlssg_for_sm86), созданный [sdli1995](https://github.com/sdli1995) и участниками проекта.
- **Адаптация для RTX 20 / SM75:** [Coldwood1026](https://github.com/Coldwood1026), указанный в [уведомлениях исходного проекта](https://github.com/sdli1995/dlssg_for_sm86/blob/main/THIRD_PARTY_NOTICES.txt).
- **Этот менеджер:** независимый интерфейс для установки и диагностики. Авторство оригинального мода принадлежит его разработчикам; менеджер не присваивает их работу и не заявляет об официальном одобрении с их стороны.

## Возможности

- Объединяет проверки ПК, выбор игры и настройки мода в обновлённом тёмном интерфейсе с прежними мятными акцентами.
- При запуске проверяет последний официальный **полный пакет релиза**, прежде чем анализировать оборудование и игру. Автоматически скачивает новый пакет и сообщает, если проверенный локальный кэш уже актуален.
- Сравнивает идентификатор релиза, идентификатор файла релиза и SHA-256, в том числе при замене файла без изменения номера версии. Состояние «нет подключения» отличается от «последняя версия».
- Проверяет архитектуру и драйвер NVIDIA, Windows x64 и настройку планирования GPU. Планирование считается подтверждённо активным только тогда, когда это отражено в журнале среды выполнения игры.
- Принимает папку игры или исполняемый файл рендеринга EXE и находит установленные игры во всех библиотеках Steam. Определяет исполняемые файлы рендеринга Unreal и позволяет вручную разрешить неоднозначный выбор.
- Проверяет архитектуру x64, поколение встроенной в игру среды DLSS-G, признаки DirectX 12, известные признаки античита, существующие загрузчики, процессы игры и свободное место. Статический анализ файлов не подтверждает, что игра обязательно будет работать.
- Показывает движок, множитель кадров, оптимизацию, пресет, переопределение SR, параметры оптического потока/HUD XeSS, загрузчик и настройки журнала. **Рекомендуемые значения: DLSS, 2×, оптимизация с точным результатом и переопределение SR Off.**
- Устанавливает или обновляет мод только после проверки и подтверждения. Подготавливает проверенные файлы, сохраняет резервную копию предыдущего состояния, отключает старые загрузчики до изменения файлов среды выполнения и активирует новый загрузчик последним.
- Позволяет отключить мод и восстановить прежнее состояние, защищает файлы, изменённые вне менеджера, и ведёт журнал восстановления для прерванных операций. Резервные копии сохраняются, включая перемещённые дополнительные файлы.
- Читает последнюю записанную сессию игры. Чтобы подтвердить фактическую генерацию кадров, требует успешного создания функции NGX 11 и её первого выполнения.
- Экспортирует локальный диагностический отчёт, скрывая пути пользователя и игры. Учётные записи и телеметрия отсутствуют.

## Скачивание и использование

Скачайте [публичную предварительную версию v0.2.0](https://github.com/VenomDrake/DLSSG-MANAGER-RTX-3000-SERIES/releases/tag/v0.2.0): [портативный ZIP](https://github.com/VenomDrake/DLSSG-MANAGER-RTX-3000-SERIES/releases/download/v0.2.0/DLSSGModManager-Portable-win-x64.zip) · [установщик Windows](https://github.com/VenomDrake/DLSSG-MANAGER-RTX-3000-SERIES/releases/download/v0.2.0/DLSSGModManager-Setup.msi). Более новые версии доступны в разделе [всех релизов](https://github.com/VenomDrake/DLSSG-MANAGER-RTX-3000-SERIES/releases).

Запустите `DLSSGModManager.exe` из портативного пакета или установите `DLSSGModManager-Setup.msi` для текущего пользователя. Для опубликованных исполняемых файлов не требуется отдельная установка .NET, Python или CUDA Toolkit.

> **Онлайн-игры: риск блокировки**
>
> Использование этого мода изменяет файлы игры. Мы настоятельно рекомендуем использовать его только в одиночных офлайн-играх. Античиты или правила игры могут расценить это как неразрешённую модификацию и привести к блокировке. Обход ограничений и защита от блокировок не предоставляются.

1. Откройте менеджер и дождитесь проверки/скачивания официального пакета мода.
2. Выберите игру Steam, папку игры или её исполняемый файл рендеринга EXE.
3. Просмотрите все проверки. Обнаруженный античит, неподдерживаемая среда выполнения, неизвестный конфликтующий загрузчик или запущенная игра блокируют установку.
4. Проверьте параметры; начните с **2×**. Нажмите **Установить мод** или **Обновить мод** и подтвердите целевую папку.
5. Запустите игру и включите **DLSS Frame Generation** в её настройках графики. Некоторым играм требуется перезапуск.
6. Нажмите **Прочитать журнал игры**, чтобы узнать, загрузился ли мод, была ли создана нужная функция и началась ли генерация кадров.

Менеджер не меняет HAGS и драйверы автоматически. Он открывает настройки графики Windows или страницу драйверов NVIDIA и показывает инструкции. После включения HAGS перезагрузите Windows.

## Обновление менеджера

Менеджер незаметно проверяет собственные релизы GitHub в фоновом режиме. Небольшое уведомление появляется только при наличии более новой стабильной версии менеджера; черновики и предварительные версии игнорируются.

Выберите **Обновить и перезапустить** в удобное время после завершения текущей операции. Менеджер автоматически выбирает портативный ZIP или MSI для текущей установки, скачивает пакет, сверяет его SHA-256 с хэшем файла официального релиза GitHub, закрывается, устанавливает обновление и открывается снова. Игры, настройки и резервные копии сохраняются. Для следующих обновлений не потребуется открывать GitHub или вручную заменять файлы.

**Переход с 0.1.0 на 0.2.0 требует одного ручного обновления**, поскольку в 0.1.0 ещё нет системы обновления. Закройте 0.1.0, затем запустите новый MSI или распакуйте весь новый портативный пакет в папку портативного приложения, используя тот же тип пакета, что и раньше. Начиная с 0.2.0, последующие обновления менеджера можно устанавливать в приложении.

Обновления менеджера и мода независимы. Обновление менеджера не устанавливает новый мод ни в одну игру; проверенная схема установки исходного проекта по-прежнему относится к версии **0.4.1**.

## Поддержка и ограничения

Версия 0.2.0 предназначена для Windows 10/11 x64 и видеокарт RTX 20/30, поддерживаемых исходным проектом. Сейчас проверена схема установки версии исходного мода **0.4.1** с драйвером R580 или новее и средой выполнения 310.9.16. Менеджер продолжает скачивать будущие официальные релизы, но неизвестная схема отмечается как неподдерживаемая, пока проверки менеджера не будут обновлены; новый номер версии сам по себе не подтверждает совместимость требований.

В игре должна быть встроена поддержка DLSS Frame Generation, и она должна работать с DirectX 12. Текущая схема исходного мода поддерживает среду выполнения 310.x; старые поколения сред выполнения отклоняются. Более высокий множитель зависит от интеграции в самой игре. Для XeSS предел — 4×; DLSS 6× требует поддержки со стороны игры.

Известные признаки античита блокируют установку. Их отсутствие не доказывает, что у игры нет античита. Не используйте внедряемые моды в сетевых играх, защищённых античитом.

Существующую ручную установку, совпадающую с текущим проверенным релизом, можно принять под управление после проверки хэшей её DLL. Более старый или неизвестный мод, установленный вручную и не имеющий записи менеджера, считается конфликтом и не перезаписывается. Установки, впоследствии выполненные менеджером, можно обновлять и восстанавливать по их перечню файлов и резервным копиям.

Первое подтверждение в журнале — это базовая проверка работоспособности, а не гарантия стабильности в длительной игре или удвоения частоты реально отрисованных кадров. Показ сгенерированных кадров и задержка ввода — разные измерения.

Менеджер и MSI в этой сборке не имеют цифровой подписи. Сертификаты подписи не импортируются. Пакет исходного проекта 0.4.1 содержит самоподписанный тестовый сертификат, имя которого отличается от указанного в его README; происхождение пакета проверяется по хэшу файла релиза GitHub, а не по доверию Windows к издателю.

## Языки

Исходный язык — английский; также доступны итальянский, упрощённый китайский, хинди, испанский, французский, арабский, бенгальский, португальский, русский и урду. Приложение выбирает поддерживаемый язык интерфейса Windows и позволяет изменить его. Для арабского и урду используется расположение справа налево. Все 11 файлов ресурсов содержат одинаковые ключи; приветствуется проверка переводов сообществом. Технические значения расширенных настроек и подробности диагностических исключений могут сохранять исходные названия.

## Локальные данные и восстановление

- Проверенный кэш пакетов и выбранный язык: `%LOCALAPPDATA%\DLSSGModManager`.
- Перечень файлов установки игры: `.dlssg-manager.json` рядом с EXE рендеринга.
- Резервные копии: `.dlssg-manager-backups` рядом с этим EXE. Сохраняйте эту папку, чтобы не потерять историю восстановления.
- Файл `.dlssg-manager.transaction.json` отмечает прерванную операцию; следующая установка/восстановление/отключение сначала выполняет восстановление после прерывания и требует закрыть игру.

Нажимайте **Восстановить предыдущее состояние** повторно, чтобы последовательно отменять обновления, сделанные менеджером. Восстановление первой управляемой установки возвращает исходное состояние, включая принятую под управление ручную установку. Отключение лишь меняет активное DLL-имя принадлежащего менеджеру загрузчика. Менеджер не удаляет неизвестные пользовательские файлы и не отменяет незаметно изменения управляемых файлов, сделанные вне него.

Удаление менеджера средствами Windows удаляет само приложение, но не моды, установленные в играх. Если вы хотите удалить и эти моды, сначала восстановите соответствующие игры. Резервные копии игр и скачанный кэш сохраняются.

## Сборка и тестирование

Установите .NET 10 SDK на Windows x64, затем выполните:

```powershell
.\scripts\test.ps1
.\scripts\build.ps1
```

Сценарий сборки создаёт автономное однофайловое приложение, портативный ZIP, MSI и контрольные суммы SHA-256 в `artifacts`. При необходимости WiX 4.0.6 устанавливается как инструмент сборки в `tools`. Скачанные DLL мода в результат сборки не включаются.

Тесты используют искусственные пакеты и безвредную тестовую DLL x64 с метаданными версии. Им не нужны игра, оборудование NVIDIA или подключение к сети. Необязательная проверка реального релиза доступна командой `dotnet run --project tests/ReleaseTests -- --live`.

Для предварительного просмотра интерфейса с локальной игрой в режиме только для чтения:

```powershell
dotnet run --project src/DlssgManager.Desktop -- --read-only --game 'D:\Games\Example'
```

`--data-dir <path>` изолирует кэш и настройки менеджера для тестирования. `--read-only` запрещает изменение файлов игры.

## Публикация собственного форка

Создайте публичный репозиторий GitHub и отправьте в него это дерево исходного кода. Включённый workflow для Windows собирает приложение и запускает тесты для pull request и отправок в основную ветку. Тег наподобие `v0.2.0` также публикует исполняемые файлы как релиз GitHub с помощью токена Actions этого репозитория. Токены не хранятся в исходном коде и не требуются конечным пользователям.
